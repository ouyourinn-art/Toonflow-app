# 耀好原创工作室

原创工作室基于 Toonflow v2.0.8 改造，开发分支为 `yaohao`，`master` 保留用于跟随上游。原视频重绘程序继续在独立仓库维护。

## 当前功能

- 首页提供原创短剧、小说改编和继续项目三个入口。
- 新项目建立七个阶段画布，每个画布含可编辑的创作说明与正文节点。
- 工作区阶段导航直接打开对应画布；切换前保存当前正文及画布，失败时显示错误。
- 项目模式和创作需求保存在 `originalProject.json`，旧项目仍可通过原有画布入口打开。
- 没有选择语言模型时，纯文字需求保存为草稿。选定模型后，首页请求交给现有助手，先完善故事构思。
- 阶段说明和助手请求要求先确认完整剧本、统一角色 ID 与别名，再安排人物及场景资产；生图、生视频提示词保留在对应画布供编辑。
- Shugando 设置可填写 API 地址、Key、协议，获取或手动输入上游模型 ID，并保存到现有模型配置。助手与文本节点共用供应商列表。
- 移除首页官方探索、TF-Router 引导登录、官方充值和云插件市场入口，停用官方使用统计；新安装不再预装 TF-Router。
- 桌面应用标识和更新地址指向耀好 Fork。原作署名及 MIT LICENSE 保留。

阶段导航显示当前打开的画布，不把点击导航当作阶段完成。各阶段目前通过画布内容与助手协作，尚未实现结构化剧本审批、强制角色锁定、跨阶段依赖校验与自动任务编排。

## 使用

1. 在引导页或设置中的「Shugando 服务」填写连接信息，获取模型后选择需要使用的模型并保存。
2. 选择创作模式，填写需求，按需添加小说等附件，选择一个空文件夹作为项目目录。
3. 通过顶部阶段导航编辑正文；助手可调用已有画布工具协助创作。每一阶段先核对前序内容再继续。
4. 在人物与资产阶段整理同一角色的姓名、别名和外观，确认后使用现有图片节点生成资产。
5. 在分镜图及视频阶段查看、调整提示词，选择实际媒体供应商和模型后提交生成。

语言模型的 API 配置不会自动配置媒体供应商，也不会自动登录 Shugando 钱包。媒体模型继续通过原有媒体设置配置。当前不默认提交付费生成任务。

## 开发与构建

使用 Bun 1.4.3。首次准备桌面 SDK 后再执行类型检查：

```powershell
bun install --frozen-lockfile
bun apps/desktop/node_modules/electrobun/bin/electrobun.cjs prepare
bun run typecheck
bun run build
bun run build:nodes
```

开发启动：

```powershell
bun run dev
```

单独预览构建页面，可指定独立数据目录，避免改动现有配置：

```powershell
$env:TOONFLOW_SERVER_PORT = '3108'
$env:TOONFLOW_DATA_DIR = Join-Path (Get-Location) 'data/originalReadyData'
$env:NODE_ENV = 'production'
bun apps/server/src/index.ts
```

访问 `http://127.0.0.1:3108`。生产服务器预览使用数据目录下的 `workspaces`；桌面端和本机开发模式沿用原生目录选择。

`bun run build:desktop` 和 `bun run package:desktop` 为已有桌面构建入口。当前阶段尚未交付耀好独立 EXE 安装包；启动画面、安装器、协议隔离与发布产物需要在打包阶段统一完成。推送开发分支不等于发布安装包或部署到云服务器。
